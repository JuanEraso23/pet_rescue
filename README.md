# Pet Rescue.

Producto de software desarrollado para la materia Ingeniería de Software 2 mediante Scrum.

## Objetivo

Facilitar el reporte, la búsqueda y la identificación de mascotas extraviadas para aumentar las posibilidades de reunirlas con sus propietarios.

## Equipo Scrum

- Product Owner: Diego Escobar Enríquez
- Scrum Master: Juan Manuel Eraso
- Developer: Jaider

## Tecnologías

- Frontend: Flutter y Dart
- Backend: FastAPI y Python
- Base de datos: PostgreSQL
- ORM: SQLAlchemy
- Prototipos: Figma
- Control de versiones: Git y GitHub

## Estructura

- frontend/: aplicación desarrollada con Flutter.
- backend/: API REST desarrollada con FastAPI.
- database/: diagramas, scripts y datos de prueba.
- docs/: documentación Scrum y evidencias del proyecto.

## Sprint actual

Sprint 01.

## Objetivo del Sprint 01

Permitir que los propietarios registren un reporte estructurado de una mascota extraviada, incluyendo fotografías, características físicas, información sobre el extravío y un medio de contacto seguro.

## Historias seleccionadas

- HU1: registrar un reporte de pérdida.
- HU2: agregar fotografías recientes.
- HU3: registrar las características físicas.
- HU4: indicar lugar, fecha y hora aproximada del extravío.
- HU5: proporcionar un medio de contacto seguro.

## Meta mínima del avance

- HU1 en estado Done.
- HU3 en estado Done.
- HU4 en estado In Progress con un avance demostrable.
