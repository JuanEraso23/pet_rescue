# HU1: Registrar reporte de pérdida

## Descripción

Como propietario de una mascota, quiero registrar un reporte de pérdida para aumentar las posibilidades de encontrarla.

## Prioridad

Alta.

## Estado

To Do.

## Sprint

Sprint 01.

## Responsable funcional

Diego, Product Owner.

## Criterios de aceptación

1. El usuario puede acceder al formulario de reporte.
2. El sistema identifica los campos obligatorios.
3. El sistema rechaza información incompleta.
4. El sistema almacena correctamente un reporte válido.
5. El reporte recibe el estado Activo.
6. El sistema muestra una confirmación.
7. El usuario puede visualizar la información registrada.

## Dependencias

- Modelo de datos.
- Endpoint de creación.
- Formulario Flutter.
- Conexión con PostgreSQL.
- Integración entre frontend y backend.
