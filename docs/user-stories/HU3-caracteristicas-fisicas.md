\# HU3: Registrar características físicas



\## Descripción



Como propietario de una mascota, quiero registrar sus características físicas para facilitar su identificación y diferenciarla de otras mascotas reportadas.



\## Prioridad



Alta.



\## Sprint



Sprint 01.



\## Estado



Done.



\## Criterios de aceptación



1\. El usuario puede seleccionar la especie de la mascota.

2\. El usuario puede registrar el nombre de la mascota de forma opcional.

3\. El usuario puede registrar la raza de forma opcional.

4\. El usuario debe registrar el color principal.

5\. El usuario debe seleccionar el tamaño.

6\. El usuario puede registrar una edad aproximada no negativa.

7\. El usuario puede registrar señas particulares.

8\. El sistema rechaza el formulario si falta la especie, el color o el tamaño.

9\. Las características quedan almacenadas en PostgreSQL.

10\. Las características registradas aparecen en el detalle del reporte.



\## Campos obligatorios



\- Especie.

\- Color principal.

\- Tamaño.



\## Campos opcionales



\- Nombre.

\- Raza.

\- Edad aproximada.

\- Señas particulares.



\## Valores permitidos



\### Especie



\- Perro.

\- Gato.

\- Ave.

\- Roedor.

\- Otro.



\### Tamaño



\- Pequeño.

\- Mediano.

\- Grande.
